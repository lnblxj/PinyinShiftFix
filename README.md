# PinyinShiftFix

Windows 10 微软拼音全角异常补丁。

## 功能原理

修改系统输入法组件中的 Shift 按键映射，并关闭当前用户的全半角切换快捷键。

## 使用

从源码构建（推荐），或使用Release中提供的程序包：

1. 运行 `PinyinShiftFix.exe`，允许管理员确认。
2. 点击“安装补丁”。操作会重启输入服务。
3. 日志显示 `INSTALLED` 后即可关闭工具。
4. 撤销时点击“从备份还原”。

备份位于 `%ProgramData%\PinyinShiftFix`，请保留以便还原。修改会使系统文件的原数字签名失效；Windows 更新或 SFC 可能恢复原版，届时需要重新分析安装。请使用输入法所在账户提权操作。

## 兼容性

- **10.0.19041.2913 / AMD64**：安装、还原与输入测试通过；同一磁盘补丁此前已验证整机重启后有效。
- **10.0.19041.6456 / AMD64**：样本静态验证通过，尚未在对应系统运行验证。
- **其他 AMD64 版本**：下载匹配的微软公开符号，按实际结构定位；无法可靠识别时停止。

两个已知版本可离线识别；其他版本分析阶段需联网，若分析失败可借助AI工具参照“构建与开发”开发专用版本。
